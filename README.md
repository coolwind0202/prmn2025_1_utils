## 機能
### 投票からグループ用のロール割り当て
- 機能概要
    1. 対象のメッセージに含まれる投票の各選択肢を取得します。
    2. 選択肢に対応する「（選択肢名）グループ」という名前のロールを取得します。
    3. 選択肢を選択したメンバーに、対応するロールを割り当てます。
    4. 以上の手順により、たとえば「A」を選択したメンバーには「Aグループ」ロールが割り当てられます。
- 使用方法
    1. 選択肢が「A」「B」...となっている投票の上で右クリックする。
    2. メニューの中にある「アプリ」を選び、`add_role_from_pole`をクリックする。

### ロール割り当ての誤りをチェック
- 機能概要
    1. B2ロールをもつすべてのメンバーを取得します。
    2. それぞれのメンバーに対し、「○○グループ」ロールの割り当て個数を確認します。
    3. もし、一個も割り当てられていなかったり、2個以上割り当てられている場合は、それらのメンバー名を表示します。
- 使用方法
    1. 任意のテキストチャンネル上で、入力欄に`/`と入力する。
    2. 選択肢が表示されるので、`validate_role`をクリックする。
### 振り返りスレッドの作成
- 機能概要
    1. 「B2」ロールを持ったメンバーのうち、コマンドを実行したチャンネルを閲覧できるメンバーを検索します。
    2. 各メンバーに対してスレッドを作成します。
- 使用方法
    1. 「計画・振り返り」チャンネル上で、入力欄に`/`と入力する。
    2. 選択肢が表示されるので、`/create_reviews`をクリックする。

## 使用手順
1. このリポジトリを、GitHub Codespaceで開く。
2. Codespace上に、「.env」というファイルを、別途指定する内容で作成する。
3. Codespace上でターミナルを開き、`npm run install`と実行する。
4. 続けて、`npm run dev`と実行する。
